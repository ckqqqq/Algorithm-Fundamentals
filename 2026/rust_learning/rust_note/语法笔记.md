## Cargo有什么用?
* Cargo 是 Rust 的构建工具和包管理器，核心作用包括：
    * 构建项目
    * 负责把源代码编译成可执行文件或库
    * 管理编译流程、依赖编译顺序、增量编译
    * 依赖管理
    * 从 Cargo.toml 读取依赖项
        * 自动下载和缓存第三方 crates
        * 生成 Cargo.lock 以锁定版本，保证可重复构建
    * 项目组织
        * 支持单个 crate、workspace、多 crate 组合
        * 管理 crate 之间的关联关系和共享依赖
            * crate 可以是：
                * 一个库（library crate）
                * 一个可执行程序（binary crate）
                * 每个 Rust 项目至少有一个 crate：
                * src/main.rs 对应一个二进制 crate
                * src/lib.rs 对应一个库 crate
    * 测试和发布
        * 提供 cargo test、cargo bench、cargo doc
        * 支持 cargo publish 发布到 crates.io
    * 工作流一致性
        * 统一命令行接口：cargo build/run/test/clean
        * 统一配置文件和目录结构
        * 内置构建配置：release/debug、features、profiles
