# 线段树（Segment Tree）— Python 模板

> 适用：区间求和 / 最值 / gcd 等任意"可合并"的运算；配合懒标记可支持区间整体加减。
> 单点修改、区间查询都是 **O(log n)**。

---

## 版本一：迭代线段树（AtCoder / zkw 风格）— 最快

适用：**单点修改 + 区间求和**。非递归，没有函数调用开销，Python 下明显快于递归版。

```python
"""
迭代线段树（AtCoder 风格）
- 单点修改 O(log n)，区间查询 O(log n)
- 用数组实现，下标从 1 开始；叶子在 [size, 2*size) 这一段
"""
class IterativeSegmentTree:
    def __init__(self, data):
        # size = 大于等于 len(data) 的最小的 2 的幂
        self.size = 1
        while self.size < len(data):
            self.size <<= 1
        # 底层数组，容量 2*size；多的位置补 0
        self.tree = [0] * (2 * self.size)

        # 初始化叶子
        for index, value in enumerate(data):
            self.tree[self.size + index] = value
        # 自底向上建树：父节点 = 两个子节点之和
        for node in range(self.size - 1, 0, -1):
            self.tree[node] = self.tree[node << 1] + self.tree[node << 1 | 1]

    def update(self, index, value):
        """把下标 index（0-based）的值改成 value"""
        position = self.size + index   # 定位到叶子
        self.tree[position] = value
        position >>= 1
        # 从叶子一路更新到根
        while position >= 1:
            self.tree[position] = self.tree[position << 1] + self.tree[position << 1 | 1]
            position >>= 1

    def range_sum(self, left, right):
        """求 [left, right) 左闭右开区间的和"""
        left += self.size
        right += self.size
        result = 0
        while left < right:
            if left & 1:               # left 是右孩子 → 直接累加
                result += self.tree[left]
                left += 1
            if right & 1:              # right 是右孩子 → 把左边的兄弟累加
                right -= 1
                result += self.tree[right]
            left >>= 1
            right >>= 1
        return result
```

**性能要点：**
- 用 `<< 1` / `| 1` 代替 `* 2` / `+ 1`，位运算更快；
- 非递归 → 没有 Python 递归开销；
- `left += self.size` 直接做偏移，`left += 1` 之后 `>>= 1` 是标准"爬树"套路。

## 版本二：递归 + 懒标记 — 区间加 + 区间求和

适用：**区间整体加减**（如"把 [l,r] 每个数 +v"）。懒标记让区间修改变成 O(log n)。

```python
"""
递归线段树 + 懒标记（Lazy Propagation）
- 区间加 O(log n)，区间求和 O(log n)
- 树和懒标记都用数组存，避免对象 / 字典的开销
"""
class LazySegmentTree:
    def __init__(self, data):
        self.n = len(data)
        self.tree = [0] * (4 * self.n)   # 节点区间的和
        self.lazy = [0] * (4 * self.n)   # 懒标记：区间整体待加的值
        self._build(1, 0, self.n - 1, data)

    def _build(self, node, start, end, data):
        if start == end:
            self.tree[node] = data[start]
            return
        mid = (start + end) >> 1
        self._build(node << 1, start, mid, data)
        self._build(node << 1 | 1, mid + 1, end, data)
        self.tree[node] = self.tree[node << 1] + self.tree[node << 1 | 1]

    def _apply(self, node, start, end, value):
        """给 node 对应的整个区间加上 value（只更新节点，不打到叶子）"""
        self.tree[node] += (end - start + 1) * value
        self.lazy[node] += value

    def _push_down(self, node, start, end):
        """把懒标记下推给两个孩子"""
        if self.lazy[node] != 0:
            mid = (start + end) >> 1
            self._apply(node << 1, start, mid, self.lazy[node])
            self._apply(node << 1 | 1, mid + 1, end, self.lazy[node])
            self.lazy[node] = 0

    def range_add(self, ql, qr, value):
        """区间 [ql, qr) 整体加上 value（左闭右开，和迭代版保持一致）"""
        if ql >= qr:
            return
        # 内部递归用闭区间 [ql, qr]，所以把排他的右端点 -1
        self._range_add(1, 0, self.n - 1, ql, qr - 1, value)

    def _range_add(self, node, start, end, ql, qr, value):
        if ql <= start and end <= qr:      # 完全被覆盖 → 打懒标记即可，不用往下
            self._apply(node, start, end, value)
            return
        self._push_down(node, start, end)  # 部分覆盖 → 先把标记下推
        mid = (start + end) >> 1
        if ql <= mid:
            self._range_add(node << 1, start, mid, ql, qr, value)
        if qr > mid:
            self._range_add(node << 1 | 1, mid + 1, end, ql, qr, value)
        self.tree[node] = self.tree[node << 1] + self.tree[node << 1 | 1]

    def range_sum(self, ql, qr):
        """求 [ql, qr) 左闭右开的区间和"""
        if ql >= qr:
            return 0
        return self._range_sum(1, 0, self.n - 1, ql, qr - 1)

    def _range_sum(self, node, start, end, ql, qr):
        if ql <= start and end <= qr:
            return self.tree[node]
        self._push_down(node, start, end)  # 查询前也要先把懒标记下推
        mid = (start + end) >> 1
        result = 0
        if ql <= mid:
            result += self._range_sum(node << 1, start, mid, ql, qr)
        if qr > mid:
            result += self._range_sum(node << 1 | 1, mid + 1, end, ql, qr)
        return result
```

**懒标记的核心思想：** 区间修改时只改"恰好覆盖该区间"的节点并记下标记，**不下推到叶子**；等将来要访问子区间时，再把标记"下推"下去。这样区间加就是 O(log n)。

## Python 性能注意事项（重要）

1. **跑题快读**：把输入一次读完，别用 `input()` 一行行读。
   ```python
   import sys
   data = list(map(int, sys.stdin.buffer.read().split()))
   ```
   `sys.stdin.buffer` 比 `sys.stdin` 快，`map(int, ...)` 比列表推导快。

2. **能选 PyPy 就选 PyPy**：循环密集的线段树在 PyPy 下通常快 3~5 倍。

3. **数组 vs 对象**：`tree`/`lazy` 用**平铺列表**，不要用 `Node` 对象或字典存区间信息——对象属性访问在 Python 里很慢。

4. **局部变量缓存**：高频函数（如递归的 `_range_sum`）里，把 `self.tree`、`self.lazy` 先 `tree = self.tree` 缓存成局部变量，能省不少属性查找时间。

5. **能用迭代版就不用递归版**：`版本一`（迭代）比 `版本二`（递归）快，因为它没有 Python 递归栈开销。只要不需要懒标记，优先迭代版。

6. **空间**：递归版数组开 `4*n`；迭代版开 `2*size`（`size` 是大于等于 n 的 2 的幂）。

## 怎么选

```
只有 单点修改 + 区间求和/异或  → 版本一（迭代，最快）
需要 区间整体加减（懒标记）    → 版本二（递归 + lazy）
需要 区间最大/最小值/gcd       → 把模板里的 "+" 换成对应运算（加法无逆，BIT 做不了）
```
