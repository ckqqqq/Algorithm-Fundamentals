# Problem 2: Tree-based Speculative Decoding

## Background

投机解码（speculative decoding）使用一个小模型（草稿模型）快速猜测若干候选 token，再由大模型（目标模型）在一次并行前向传播中统一验证。先进方法（Medusa、EAGLE）让草稿模型一次性生成一棵**候选 token 树**：根节点是已确认的上下文，每个节点是一个候选 token，大模型只需一次前向传播即可验证整棵树中的所有路径。

验证规则：从根节点出发，沿路径逐个检查节点，每个节点以给定概率被大模型接受；一旦某个节点被拒绝，它在该路径上的所有后代都会被丢弃。求这一轮验证中被接受 token 数量的期望值。

## Problem Description

给定一棵有 n 个节点的有根树，根为节点 1（根节点是已确认的上下文，**不计入**接受数量，且始终存在）。每个非根节点 i 有一个条件接受概率 p_{i}：在其父节点被接受的条件下，节点 i 以概率 p_{i} 被接受。一个节点被算作"接受"，当且仅当从它到根的路径上的所有节点（包括它自己）都被接受。

求被接受节点数量的期望值。

## Input Format

第一行包含一个整数 n，表示节点数量。

第二行包含 n-1 个整数 $f_2, f_3, \ldots, f_n$（$1 \le f_i < i$），其中 f_i 是节点 i 的父节点。

第三行包含 $n-1$ 个实数 $p_2, p_3, \ldots, p_n$，表示每个非根节点的条件接受概率。

## Output Format

输出一个实数，即被接受节点数量的期望值。答案保留 $6$ 位小数输出；与标准答案的绝对误差或相对误差不超过 $10^{-6}$ 均视为正确。

## Sample Input

```
5
1 1 2 2
0.90 0.80 0.50 0.50
```

## Sample Output

```
2.600000
```

## Sample Explanation

树的结构：根节点 1 有子节点 2 和 3；节点 2 有子节点 4 和 5。

一个节点被接受，当且仅当它到根的路径上的所有节点都被接受。每个节点被接受的概率是路径上各概率的乘积：

- 节点 2：$0.9$
- 节点 3：$0.8$
- 节点 4：$0.9 \times 0.5 = 0.45$
- 节点 5：$0.9 \times 0.5 = 0.45$

由期望的线性性，被接受节点数量的期望 $= 0.9 + 0.8 + 0.45 + 0.45 = 2.6$。

> 注意：本题的简化模型允许"同时接受多条分支"（意在考察树路径上的概率乘积 + 期望的线性性）。真实的投机解码每轮只保留一条路径；该语义见文末的"进一步思考"。

## Solution

**关键观察**：期望的线性性。每个非根节点 $i$ 被接受，当且仅当从根到 $i$ 的路径上的每个节点都被接受，其发生概率等于路径上所有 $p$ 值的乘积。因此：

$$E = \sum_{i=2}^{n} \prod_{v \in \text{path}(1 \to i)} p_v$$

做一遍 DFS/BFS，维护从根到当前节点的概率乘积 $q_i = q_{f_i} \times p_i$（$q_1 = 1$），并累加求和即可。

**复杂度**：时间 $O(n)$，空间 $O(n)$。$n \le 10^5$ 可以轻松处理。

**进一步思考**：

1. 若规则改为"只能接受一条路径"（即上文讨论的真实投机解码语义），问题就变为求树中完全被接受的最长路径的期望，可以用树形 DP 解决：设 $dp_i$ 为以 $i$ 结尾的路径的期望贡献，其中涉及对兄弟分支取最大值时的次序统计量——难度显著上升，可作为本题的后续部分。
2. 真实系统（如 EAGLE）还会对树进行剪枝（只保留 top-$k$ 分支），并优化"期望接受长度 / 验证成本"的比值，这是树上的背包类问题。

## Reference Code (C++)

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    scanf("%d", &n);
    vector<int> fa(n + 1, 0);
    for (int i = 2; i <= n; i++) scanf("%d", &fa[i]);
    vector<double> p(n + 1, 1.0), q(n + 1, 1.0);
    for (int i = 2; i <= n; i++) scanf("%lf", &p[i]);
    // 输入保证 fa[i] < i，因此按下标顺序递推一遍即可
    double ans = 0;
    for (int i = 2; i <= n; i++) {
        q[i] = q[fa[i]] * p[i];
        ans += q[i];
    }
    printf("%.6f\n", ans);
    return 0;
}
```
